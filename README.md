# Airbnb-Dashboard-for-NewYork-City
This interactive Power BI dashboard provides a comprehensive analysis of Airbnb listings in New York City. It is designed to help stakeholders—including hosts, analysts, and potential investors—gain deep insights into the short-term rental market.

**Key Features:**

1.Overview Cards: Total listings, average price per night, total number of reviews, and average rating.

2.Location Insights: Interactive map and bar charts showing listing distribution by borough (e.g., Manhattan, Brooklyn, Queens), and neighborhood.

3.Price Analysis: Average pricing trends across room types (Entire home/apt, Private room, Shared room) and boroughs.

4.Availability Trends: Analysis of listings’ availability throughout the year, highlighting high-demand months.

5.Top Listings: A spotlight on top-performing listings based on ratings and number of reviews.

6.Filter Options: Slicers for borough, room type, price range, and availability to allow users to customize the view.

**Tools & Techniques Used:**

1.Power BI Desktop for data modeling and visualization

2.DAX for creating dynamic measures (e.g., Avg. Price, Total Listings)

3.Data transformation using Power Query

4.Geo-mapping for spatial insights

This dashboard enables quick decision-making by visualizing key metrics and trends in the NYC Airbnb market, helping users identify profitable areas, ideal pricing strategies, and room preferences.
